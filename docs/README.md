# Docs Layout

This directory contains published user documentation and maintainer-only docs.

- User-facing docs: `docs/users/*.md` pages (for example `docs/users/index.md`, `docs/users/introduction.md`, `docs/users/differences.md`).
- Maintainer docs: `docs/maintainers/`.

See `docs/maintainers/README.md` for maintainer-specific references and generated artifacts.
