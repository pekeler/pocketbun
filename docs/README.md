# Docs Layout

This directory mixes published user documentation and maintainer-only docs.

- User-facing docs: top-level `docs/*.md` pages (for example `docs/index.md`, `docs/introduction.md`, `docs/differences.md`).
- Maintainer docs: `docs/maintainers/`.

See `docs/maintainers/README.md` for maintainer-specific references and generated artifacts.
