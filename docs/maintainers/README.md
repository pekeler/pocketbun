# Maintainer Docs

This folder is for internal maintainer workflows and generated metadata.

- `UPGRADING.md`: step-by-step PocketBase tag upgrade workflow.
- `upstream-docs-map.md`: mapping of PocketBase docs pages to PocketBun docs pages.
- `upstream-docs-manifest.json`: generated manifest used by docs tooling.

The manifest file is generated by `scripts/docs/rebuild_from_upstream.ts`; do not hand-edit it.
